# Admin

Proyecto desarrollado con Python, Flask, Jinja y Poetry.

## Requisitos

Antes de ejecutar el proyecto, asegurarse de tener instaladas las siguientes versiones:

- Python 3.12.3
- Poetry 2.1.4

Para verificar las versiones:

```bash
python --version
poetry --version
```

## Instalación

Instalar las dependencias del proyecto:

```bash
poetry install
```
